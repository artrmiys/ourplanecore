# Sample Guide Project

`Open / Import > Sample Job` now creates `OurPlaneCore Guide Sample`.

The generated job contains:

- `Pages/00. Guide` with PDF guide cards for workspace layout, Pages/PDF Layers, Takeoffs, viewport tools, manager tabs, Settings, and `A101 Sample Plan`.
- Preloaded takeoffs on `A101 Sample Plan`: floor area, exterior walls, doors, windows, joist area, roof area, eave guide, and rake guide.
- `AI_Context/guide/README.md` with a button map and quick workflow checklist.
- `AI_Context/guide/screenshots/*.png` with generated guide screenshots for the main workspace, Pages/Layers, Takeoffs/tools, viewport tools, and manager/settings surfaces.

The sample is intentionally local and self-contained. It does not use secrets or network calls, and the screenshots are generated guide images rather than captured live user data.
