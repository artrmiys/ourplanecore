04 — Main View Polished

Тот же Bluebeam-канон, но с продакшн-уровнем деталей:

  • Иконки в ribbon — настоящие SVG-paths (single-stroke 1.5 px), а не эмодзи. Каждая тулза имеет цветовую идентичность измерения (Line синий, Area фиолетовый, Joist зелёный, Count розовый) — перенесено из MeasurementGlyph.cs.
  • Ribbon показывает контекстуальную вкладку «Line Tools» (синий italic) — появляется только когда выделено Line-измерение. Microsoft Office UXG pattern.
  • Recording-баннер в углу канваса с пульсирующей точкой — пользователь точно знает, что геометрия пишется в активный takeoff. Esc закрывает.
  • В Markups List активная строка подсвечена с inset-акцентом слева, добавлены sticky-headers, zebra-полосы (`markups-zebra` token), фильтр по странице и статусу.
  • Status bar показывает full info: Job · Page · Scale · Zoom · XY (pt + ft/in) · Mode chips · активный takeoff с цветным свотчем · REC-индикатор · save state.
  • Профиль в title bar — Drawing v1 ▾, как в Bluebeam Profile dropdown.
