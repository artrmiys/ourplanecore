UX Mockups для SmartTakeoffs

Три направления дизайна одного и того же главного окна. Открой каждый, сравни плотность, палитру, иерархию. Контент один и тот же — Sample Project, страница A101, активный инструмент Line, два AI-наблюдения. Отличаются только визуальный язык и компоновка.

Вариант 1 · светлая

Modern Light

Linear/Figma-style. Мягкие поверхности, щедрые отступы, один акцент-цвет, скруглённые углы 6 px, активный Inspector справа, плавающая панель инструментов слева.

  • Самый «продуктовый» вид
  • Меньше визуального шума
  • Хорош для презентаций и онбординга
Вариант 2 · тёмная

Dark Studio

Blender/Figma dark. Глубокий нейтральный фон, цветные геометрии измерений «горят», минимальный chrome, тонкая типографика, focus на канвасе.

  • Максимальный контраст для измерений
  • Меньше глаз устают за 8-часовую смену
  • «Pro tool» эстетика
Вариант 3 · плотная

Bluebeam Dense

Канон отрасли. Информационная плотность, классический ribbon, строгий серый палитр, всё на виду, минимум скруглений. Знакомо эстиматорам с первой минуты.

  • Мгновенно узнаваемый workflow
  • Нулевая кривая обучения для PlanSwift/Bluebeam users
  • Максимум функций без скрытия
Файлы лежат в docs/mockups/. Это не реализация — это направление дизайна. После выбора варианта собирается финальный design system и идёт по плану из UX_DESIGN_IMPLEMENTATION_PLAN_2026_05_04.md.
