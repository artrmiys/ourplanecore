Bluebeam Dense — характеристики

Канон отрасли. Полноценный ribbon с 9 вкладками (File / Home / Markup / Measure / Document / View / Sheets / AI / контекстуальный Area Tools) и группами кнопок с подписями — мгновенное узнавание для эстиматоров, привыкших к Bluebeam Revu или PlanSwift. Контекстуальная вкладка появляется только при выборе соответствующего объекта — Microsoft Office UXG паттерн.

Правая панель разделена пополам: Takeoffs сверху, Properties снизу — это Bluebeam-канон. Status-cells (Takeoff/Reviewed/Revised/Final) встроены в Properties как сегментированный контрол.

Внизу — Markups List с табами AI Inbox / Estimating. Колонки Subject, Page, Cost Code, Status, Qty, Unit, Rate, Cost, Notes — точно как в Bluebeam estimator profile. Каждая строка имеет цветовой свотч и status pill.

Палитра серая, утилитарная, минимум скруглений (2-4 px). Это не попытка выглядеть «современно» — это попытка выглядеть «знакомо» для аудитории, которая платит за PlanSwift $1700/год. Самый низкий риск отторжения для текущей профессиональной аудитории.
