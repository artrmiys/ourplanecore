Dark Studio — характеристики

Глубокий нейтральный фон #0E1014 для канваса и #1B1D22 для панелей — глаз не выгорает за 8-часовую смену. Цвета измерений (Line синий, Area фиолетовый, Joist зелёный, Count розовый) насыщены и «горят» на тёмном фоне с лёгким glow-эффектом для свечения линий.

Тёплый янтарный акцент #FFB454 на primary-кнопках и активных состояниях даёт визуальную связку. Recording-индикатор слева в HUD — пульсирующий красный круг, чтобы пользователь точно знал, что геометрия пишется.

Toast в правом нижнем углу показывает прогресс AI-операций без раскрытия Inbox-панели. Спиннер в Inbox-баре дублирует сигнал.

Inspector аналогичен светлой версии, но карточки имеют чуть больший контраст. Тонкая типографика Inter/Segoe UI делает плотность приятной — это canonical «pro tool» эстетика 2025-2026.
